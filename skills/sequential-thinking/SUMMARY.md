# sequential-thinking SUMMARY (quickref)
1. Baseline: goal + facts (with file refs) + unknowns + constraints.
2. Decompose into numbered thoughts (claim + evidence, or next action).
3. Falsify branches early (cheapest killing test first).
4. ONE chain via MCP (cap 12 thoughts).
5. Spill longer chains to artifacts/think-NNN.md, continue from summary.
6. Handoff: conclusion + confidence + the Worker task it justifies.
Rules: never extend dead chains; every thought ends in evidence or action.
Lead-only by convention (`/think`); Workers only when tasked.
Anti-pattern: dumping 50+ raw tool lines into a thought — spill first.
