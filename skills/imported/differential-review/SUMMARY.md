# Differential review / patch diffing

Diff two versions to find the security-relevant change: new sink, missing check, authz change, or patched bug.

- Use when: A CTF gives source/binary versions, a patch, or a commit range; or you want to infer the intended bug from a fix.
- Domains: rev, web-ctf
- Source: https://github.com/trailofbits/skills/tree/main/plugins/differential-review/skills/differential-review
- Status: imported, source-verified (no CTF fixture yet)
